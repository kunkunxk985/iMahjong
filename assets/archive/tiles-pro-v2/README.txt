邳州麻将成品牌面素材 V2

这是游戏中应当使用的正式牌面素材，不是之前的规则校验图。

特点：

- 单张尺寸：270 x 390 PNG。
- 无调试文字，无牌名文字，无绿色底板。
- 万牌为传统红色汉字和“萬”。
- 一条为传统鸟牌样式，二条至九条为竹节牌样式。
- 一筒为彩色圆牌中心图案，二筒至九筒使用蓝、红、绿圆牌。
- 使用红中、绿发和空白框白板。
- 共30种唯一牌面，每种在牌库中复制4张，共120张。
- 不包含东南西北风牌、花牌、癞子或财神。

加载方式：

1. 读取 tiles.json 的 tileIds。
2. 从本目录加载对应PNG。
3. 每个 tileId 创建4个不同实例，例如 WAN_1_1 至 WAN_1_4。
4. 不要在牌面上叠加“万1”“条2”之类的调试文字。
