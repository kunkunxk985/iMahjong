# iMahjong · 邳州麻将联机桌面版

以公开资料校核的邳州麻将（查胡麻将）桌面端应用，支持 **四人联机对局**（通过 6 位数字房间号加入）与 **单机陪练模式**（与 3 位智能陪练练习打牌）。地方牌桌可能存在房规差异，项目把公开口径、实现解释和本房房规分开记录。

项目结构、逐文件职责和当前运行链见 [docs/PROJECT-STRUCTURE.md](docs/PROJECT-STRUCTURE.md)，规则来源与取舍见 [docs/邳州麻将规则考据.md](docs/邳州麻将规则考据.md)。牌桌是 2.5D CSS 实体牌，运行时素材在 `apps/desktop/public/assets/tiles/`。

## 规则特性
- **牌库 120 张**：一至九万、一至九筒、一至九条、中发白（无风牌、无花牌）。
- **标准操作**：仅吃上家、碰、坎上、送杠、自杠、平胡、起手杠胡；手里三张可接别人第四张送杠，只有已坎上的三张可在自摸第四张时自杠，碰后不能再杠。
- **查胡计分**：四家都查对子、碰、暗坎和杠，胡/幺两两结；放炮与自摸不附加全局倍率；庄家、飘荤分别只翻对应玩家本人的胡数，各自折算后再相减，幺差不翻；坎上用于锁牌和进阶组型，未锁定的真实暗坎仍计基础胡；支持两对关门、三类包庄及本房开局四同张流局。
- **四人联机**：6 位房间号一键复制、房间席位等待大厅、全员准备后房主开局、断线 30 分钟保留座位重连、再来一局按规则轮庄。

## 运行与开发

```bash
# 安装依赖
npm install

# 运行规则单元测试
npm test

# 完整验证：类型检查、规则测试、联机流程和桌面构建
npm run verify

# 3D 牌桌实际渲染回归：操作回调、按钮可见性、视角切换和 GPU 资源释放
# 需要本机 Electron 运行依赖；可用 TABLE3D_SCREENSHOT_DIR 指定截图目录
npm run test:3d -w @pizhou/desktop

# 启动桌面端（会自带本机牌局服务，单机不必再开一份）
npm run dev
# 或
npm run dev:desktop

# 只当局域网主机、不开窗口时才单独起服务端
npm run dev:server
```

桌面端会自己探测或启动本机 `8787`（被占用则用 8788+）。单机陪练连本机即可，不用先填地址。去别人电脑上联机时，在「服务器设置」填那台电脑打印的 `ws://IP:8787`。

## 打包构建

```bash
# macOS 打包并更新桌面上的唯一最新版 App
npm run package:mac

# Windows 打包
npm run package:win

# 清理桌面端构建产物
npm run clean
```

macOS 打包会把最新版覆盖复制到桌面的 `iMahjong.app`，不会再生成“新版2/新版3”这类重复副本。
