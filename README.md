# 邳州麻将联机桌面版

正统邳州麻将（查胡麻将）桌面端应用，支持 **四人联机对局**（通过 6 位房间号加入）与 **单机陪练模式**（与 3 位智能陪练练习打牌）。

项目结构和当前运行链见 [docs/PROJECT-STRUCTURE.md](docs/PROJECT-STRUCTURE.md)。当前正式牌桌使用 3D 牌桌场景，运行时素材统一从 `apps/desktop/public/assets/` 加载。

## 规则特性
- **牌库 120 张**：一至九万、一至九筒、一至九条、中发白（无风牌、无花牌）。
- **标准操作**：仅吃上家、碰、杠（明杠/暗杠/补杠）、平胡、起手杠胡。
- **正统查胡计分**：胡/幺两两结、庄家胡数翻倍、幺数不翻倍、暗刻与落地碰都算坎、点炮第三张不成坎、起手四同张流局、荒庄流局不计分。
- **四人联机**：6 位房间号一键复制、房间席位等待大厅、全员准备后房主开局、断线 30 分钟保留座位重连、再来一局按规则轮庄。

## 运行与开发

```bash
# 安装依赖
npm install

# 运行规则单元测试
npm test

# 完整验证：类型检查、规则测试、联机流程和桌面构建
npm run verify

# 启动桌面端开发客户端
npm run dev:desktop

# 或者独立启动服务端与客户端
npm run dev:server
npm run dev:desktop
```

实际联机时，让一台电脑启动 `npm run dev:server`，其他电脑在首页的“服务器设置”中填写这台电脑的局域网地址，例如 `ws://192.168.1.8:8787`，然后创建或加入同一个房间。默认的 `localhost` 只代表当前电脑。

## 打包构建

```bash
# macOS 打包并更新桌面上的唯一最新版 App
npm run package:mac

# Windows 打包
npm run package:win

# 清理桌面端构建产物
npm run clean
```

macOS 打包会把最新版覆盖复制到桌面的 `邳州麻将.app`，不会再生成“新版2/新版3”这类重复副本。
